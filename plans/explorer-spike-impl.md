# Explorer spike (step 1 of plans/explorer.md) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Answer, with measurements, whether a Quarto OJS page inside the
altdoc site can (a) load a small first-view asset, (b) read one game's plays
from a season parquet with DuckDB-WASM HTTP range requests, and (c) draw a
plotly 3D scatter, all fast enough on a phone. Then record the answer as
decision 0046.

**Architecture:** This is a throwaway `spike/explorer-ojs` branch (never
merged, per AGENTS.md Git). A scratch R script writes three assets into
`vignettes/explorer-data/`, and a scratch `vignettes/explorer-spike.qmd` uses
them through OJS. The site renders locally with altdoc, is served by a
range-capable static server, and is measured with Playwright at 390×844. Only
the decision record (on `docs/explorer-spec`) survives.

**Tech Stack:** R (arrow, dplyr, jsonlite), Quarto 1.8 OJS, `@duckdb/duckdb-wasm`
(jsDelivr ESM), plotly.js gl3d partial bundle, Observable Plot, Playwright
MCP, `npx http-server`.

**Known facts going in:**
- altdoc's `quarto_website` copies the whole `vignettes/` dir into
  `_quarto/vignettes/` before rendering, so `vignettes/explorer-data/` comes
  along.
- Quarto copies only the resources it detects to the output. Files fetched at
  runtime by JS must be listed under `resources:` in the page front matter.
- Python's `http.server` does not answer Range requests, so it can't be used
  to test range reads. `npx http-server` does.
- `site.yaml` renders with `altdoc::render_docs(freeze = TRUE)`, using the
  committed `_quarto/_freeze/`.
- Local `data/` has `plays.parquet` (3.1M rows, 2010–2026), `games`,
  `combine`, and `teams`.

### Task 2: Scratch asset writer

**Files:**
- Create: `data-raw/spike-explorer-assets.R`

- [ ] **Step 1: Write the script**

```r
# Spike only (spike/explorer-ojs): write the three assets the spike page reads.
pkgload::load_all(quiet = TRUE)
library(dplyr)
out <- "vignettes/explorer-data"
dir.create(out, showWarnings = FALSE, recursive = TRUE)

games <- arrow::read_parquet("data/games.parquet")
teams <- arrow::read_parquet("data/teams.parquet")

# team x season: end Elo + W/L, both sides of each completed game.
side <- function(g, us, them) {
  transmute(
    g,
    season, week, startDate,
    team_id = .data[[paste0(us, "Id")]],
    pts = .data[[paste0(us, "Points")]],
    opp = .data[[paste0(them, "Points")]],
    elo = .data[[paste0(us, "PostgameElo")]]
  )
}
done <- filter(games, completed)
team_season <- bind_rows(side(done, "home", "away"), side(done, "away", "home")) |>
  arrange(team_id, season, startDate) |>
  group_by(team_id, season) |>
  summarise(
    w = sum(pts > opp, na.rm = TRUE),
    l = sum(pts < opp, na.rm = TRUE),
    elo = last(stats::na.omit(elo)),
    .groups = "drop"
  ) |>
  left_join(select(teams, team_id, team, color, logo = logo_light), by = "team_id")
jsonlite::write_json(team_season, file.path(out, "team_season.json"), na = "null")

# plays: one parquet per season, sorted by gameId, small row groups so a
# single game maps to few byte ranges.
plays <- arrow::open_dataset("data/plays.parquet")
for (s in 2010:2026) {
  plays |>
    filter(season == s) |>
    select(gameId, id, period, clock_minutes, clock_seconds, offense, defense,
           offenseScore, defenseScore, down, distance, yardsToGoal,
           playType, ppa, playText) |>
    collect() |>
    arrange(gameId, as.numeric(id)) |>
    arrow::write_parquet(file.path(out, sprintf("plays_%d.parquet", s)),
                         chunk_size = 5000L)
}

combine <- arrow::read_parquet("data/combine.parquet") |>
  transmute(player_name, pos, season, height, weight, forty,
            drafted = !is.na(draft_round), athlete_id)
jsonlite::write_json(combine, file.path(out, "combine.json"), na = "null")

# Q6 fallback sizing: per-team-season JSON for plays (measured, then deleted).
tmp <- file.path(tempdir(), "plays-json"); dir.create(tmp, showWarnings = FALSE)
p <- plays |> filter(season == 2025L) |> collect()
for (t in unique(c(p$offense, p$defense))) {
  jsonlite::write_json(filter(p, offense == t | defense == t),
                       file.path(tmp, paste0(make.names(t), ".json")))
}
f <- list.files(tmp, full.names = TRUE)
cat(sprintf("Q6 2025 per-team JSON: %d files, %.1f MB\n",
            length(f), sum(file.size(f)) / 1e6))
print(file.size(list.files(out, full.names = TRUE)) |>
  setNames(list.files(out)))
```

```{ojs}
//| echo: false
duckdb = import("https://cdn.jsdelivr.net/npm/@duckdb/duckdb-wasm@1.29.0/+esm")
db = {
  const bundle = await duckdb.selectBundle(duckdb.getJsDelivrBundles());
  const workerUrl = URL.createObjectURL(
    new Blob([`importScripts("${bundle.mainWorker}");`], {type: "text/javascript"}));
  const d = new duckdb.AsyncDuckDB(new duckdb.ConsoleLogger(), new Worker(workerUrl));
  await d.instantiate(bundle.mainModule, bundle.pthreadWorker);
  return d;
}
gamePlays = {
  if (!gameId) return [];
  const t0 = performance.now();
  const url = new URL(`explorer-data/plays_${season}.parquet`, location.href).href;
  await db.registerFileURL(`plays_${season}.parquet`, url,
    duckdb.DuckDBDataProtocol.HTTP, false);
  const conn = await db.connect();
  const res = await conn.query(
    `select * from 'plays_${season}.parquet' where gameId = ${+gameId}`);
  await conn.close();
  const rows = res.toArray().map(r => r.toJSON());
  console.log(`SPIKE game read: ${rows.length} rows in ${Math.round(performance.now() - t0)} ms`);
  return rows;
}
Inputs.table(gamePlays, {rows: 12})
```
